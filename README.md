# ⚽ Polla Mundialista — Combuses

Juego de predicciones de los partidos de **Colombia en el Mundial 2026**, creado por **COMBUSES S.A.**

Los empleados ingresan su cédula, pronostican el resultado (y marcador) de cada partido, y pueden consultar estadísticas en vivo y la tabla de líderes.

## Funcionalidades

- ✅ Validación de participantes por cédula.
- 🎯 Predicción de resultado (gana / empata / pierde) + marcador exacto opcional.
- 📊 Estadísticas en vivo: cuántos han votado y qué opina la gente.
- 🏆 Resultados reales y tabla de líderes automática.

## Tecnología

- **HTML + CSS + JavaScript** (un solo archivo, sin dependencias).
- **Supabase** para guardar las predicciones.
- **API openfootball** para los partidos y resultados reales del Mundial 2026.
- Banderas de **flagcdn.com**.

## Puntaje

- 🎯 Marcador exacto correcto → **5 puntos**
- ✅ Solo el resultado correcto → **3 puntos**
- ❌ Fallar → 0 puntos
